# Class 15. Capstone M1: Ask

**When:** Fri 30 Oct 2026, 19:45-21:15 (in person, 90 min)  
**Data:** Own data

**Goal:** Students register a question and import a dataset.

## Plan

| Minutes | Activity |
|---|---|
| 0-15 | Pick one question. Write the one-sentence message you expect. |
| 15-45 | Import the data with `read_csv(here(...))`. |
| 45-80 | Tidy check (one row per observation, one column per variable, no values in column names) and the [data quality checklist](../../capstone/data_quality_checklist.md). |
| 80-90 | Register the question in Moodle. |

## Reading

Individual work (about 30 minutes). Read it before the class if possible:

- Ellis and Leek, [How to share data for collaboration](https://www.tandfonline.com/doi/full/10.1080/00031305.2017.1375987).
- [R4DS 2e](https://r4ds.hadley.nz/), chapter 7, Data import.

## Deliverable

Question in Moodle and a script with import and tidy check.
