# Class 03. Know your data: type decides the chart

**When:** Sat 17 Oct 2026, 09:00-10:30 (in person, 90 min)  
**Data:** Penguins

**Goal:** Students pick a chart from the type of each variable.

## Plan

| Minutes | Activity |
|---|---|
| 0-15 | Why data knowledge comes first. `glimpse()`, `is.na()`, number, category, date. |
| 15-45 | One number: histogram. Two numbers: scatter. One category: bar of counts. Number by category: box plot. Time: line. |
| 45-70 | Add variables with color, shape, size and facet. Explain why 3D adds nothing. |
| 70-90 | Students fill the chart-by-type map with five graphs. |

## Deliverable

Chart-by-type map filled with five graphs.
