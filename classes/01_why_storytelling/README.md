# Class 01. Why storytelling matters

**When:** Sat 10 Oct 2026, 13:45-15:15 (in person, 90 min)  
**Data:** Examples

**Goal:** Students list the mistakes in bad graphs and set up a working RStudio project.

## Plan

| Minutes | Activity |
|---|---|
| 0-15 | Welcome. Course map, the five principles (Ask, Show, Cut, Focus, Tell), grading. |
| 15-45 | Bad graphs I: truncated bars, 3D pie, dual axes, spaghetti lines, missing source. Students find the mistake in each before you reveal it. |
| 45-70 | Data errors behind bad graphs: wrong units, missing values coded as 0, a sum that exceeds 100%, a wide table plotted as it is. One example for each. |
| 70-90 | Setup: create an RStudio Project (`.Rproj`), open the console, run `1 + 1`, install packages with `pacman::p_load(tidyverse, here)`, show `here()` and relative paths. |

## Deliverable

A list of mistakes found in the examples, and a working project folder.

## Notes

Students install R, RStudio and the tidyverse before class (see the welcome email). Use the Zoom help session on Fri 9 Oct for installs.
