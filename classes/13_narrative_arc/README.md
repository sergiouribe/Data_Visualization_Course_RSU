# Class 13. Narrative arc

**When:** Thu 29 Oct 2026, 18:00-19:30 (in person, 90 min)  
**Data:** Rosling chart

**Goal:** Students write a one-sentence message and a 60-second script.

## Plan

| Minutes | Activity |
|---|---|
| 0-10 | Beginning, middle, end (Knaflic chapter 7). |
| 10-40 | Watch the first 5 minutes of Rosling's talk. Score it from 0 to 2 on Ask, Show, Cut, Focus, Tell. |
| 40-70 | Write the one-sentence message of your Rosling chart. |
| 70-90 | Write and rehearse a 60-second script in pairs. |

## Reading

Individual work (about 30 minutes). Read it before the class if possible:

- Knaflic, *Storytelling with Data*, chapter 7, Lessons in storytelling.
- [Points of view: Storytelling](https://www.nature.com/articles/nmeth.2571), Nature Methods 10, 687.

## Deliverable

One-sentence message and a 60-second script.
