# Class 13. Small multiples and narrative arc

**When:** Thu 29 Oct 2026, 18:00-19:30 (in person, 90 min)  
**Data:** `data/rosling_tidy.csv`, Rosling's talk

**Goal:** Students compare 1952 and 2007 with facets, then write the 60-second script of their Rosling chart.

## Plan

| Minutes | Activity |
|---|---|
| 0-10 | Why small multiples beat animation for comparison. |
| 10-30 | `facet_wrap()` and `facet_grid()` on the Rosling chart. |
| 30-40 | Students choose the best layout and justify it in one sentence. |
| 40-50 | Beginning, middle, end (Knaflic chapter 7). |
| 50-65 | Watch the first 5 minutes of Rosling's talk. Score it from 0 to 2 on Ask, Show, Cut, Focus, Tell. |
| 65-90 | Pairs rehearse a 60-second script around the one-sentence message from class 12. |

## Reading

Individual work (about 30 minutes). Read it before the class if possible:

- Knaflic, *Storytelling with Data*, chapter 7, Lessons in storytelling.
- [Points of view: Storytelling](https://www.nature.com/articles/nmeth.2571), Nature Methods 10, 687.
- [Points of view: Multidimensional data](https://www.nature.com/articles/nmeth.2531), Nature Methods 10, 595.
- [R4DS 2e](https://r4ds.hadley.nz/), chapter 9, Layers (facets).

## Deliverable

Faceted Rosling chart, one-sentence message and a 60-second script.
