# Class 14. Quarto reports, animation demo and capstone questions

**When:** Thu 29 Oct 2026, 19:45-21:15 (in person, 90 min)  
**Data:** Own ideas

**Goal:** Each student leaves with two candidate capstone questions.

## Plan

| Minutes | Activity |
|---|---|
| 0-20 | Reporting and sharing: a `.qmd` file is a report. Header (YAML), text, chunks. Click **Render** to make an HTML file, then change `format:` to `pdf` or `docx`. `embed-resources: true` gives one file to share. Quarto is the successor to R Markdown and uses the same chunks. |
| 20-30 | Optional `gganimate` demo on the teacher's screen. If installs fail, show only the teacher's screen. |
| 30-40 | Dataset sources: TidyTuesday, FiveThirtyEight, Our World in Data, Kaggle, DrivenData, national statistics. Any dataset is allowed. |
| 40-82 | Workshop: write two questions, check that each dataset has the variables you need. |
| 82-90 | Two-minute pitch to a neighbor. |

## Reading

Individual work (about 30 minutes). Read it before the class if possible:

- [R4DS 2e](https://r4ds.hadley.nz/), chapters 28 and 29, Quarto and Quarto formats.

## Deliverable

Two candidate questions per student.
