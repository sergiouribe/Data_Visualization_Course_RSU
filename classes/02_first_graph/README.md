# Class 02. Grammar of graphics: data, aes, geom

**When:** Sat 10 Oct 2026, 15:30-17:00 (in person, 90 min)  
**Data:** Penguins

**Goal:** Students draw a first scatter plot and save it with a one-line question.

## Plan

| Minutes | Activity |
|---|---|
| 0-10 | Question: do penguins with longer flippers weigh more? Write it in a comment. |
| 10-30 | Teacher demo of `data + aes + geom` and the pipe `|>`. |
| 30-65 | Students run `02_first_graph.qmd`, change variables, add color. |
| 65-80 | Save with `ggsave(here(...))`. Pair check: does the graph answer the question? |
| 80-90 | Recap: three parts of every ggplot. |

## Deliverable

First graph with a one-line question, saved in the project.

Penguins first because the data is small, clean and has both numbers and categories.
