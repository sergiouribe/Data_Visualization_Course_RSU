# Class 12. Rosling polish and export

**When:** Sat 24 Oct 2026, 14:15-15:45 (in person, 90 min)  
**Data:** Gapminder

**Goal:** Students finish the Rosling chart and export it.

## Plan

| Minutes | Activity |
|---|---|
| 0-10 | Five-principle checklist. |
| 10-35 | Alpha for overlap. Direct labels with `geom_text_repel()`. |
| 35-60 | Advanced customization: `scale_color_manual()` with named colors, `theme()` options, title aligned to the plot edge. |
| 60-75 | Active title, subtitle, source. |
| 75-90 | `ggsave(dpi = 300)`. Gallery walk: each student reads one title aloud. |

## Reading

Individual work (about 30 minutes). Read it before the class if possible:

- [Design of data figures](https://www.nature.com/articles/nmeth0910-665), Nature Methods 7, 665.
- [BBC Visual and Data Journalism cookbook for R graphics](https://bbc.github.io/rcookbook/).
- [Data visualisation: charts](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/#relevant-success-criteria-for-charts), UK Government Analysis Function.

## Deliverable

Final Rosling PNG at 300 dpi.
